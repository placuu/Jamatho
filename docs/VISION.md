# Vision — Jamatho

## Problem

Primary and secondary school kids (ages 6–14) often find math intimidating. Existing tools are either too dry (digital worksheets) or too gamified (distracting from actual learning). There is a gap for a structured, step-by-step math learning platform that balances explanation, guided practice, and progress visibility for both kids and parents.

## Solution

Jamatho is a web application where kids learn math through short lessons with step-by-step guidance, practice exercises with hints, and end-of-lesson tests — all organized by category and difficulty. Parents can monitor progress through a dedicated dashboard.

## Target Users

| User | Needs |
|------|-------|
| Kids (6–10) | Arithmetic, geometry basics, simple explanations, instant help |
| Kids (11–14) | Fractions, decimals, intro algebra, self-paced progression |
| Parents | Visibility into child's progress, strengths, and weaknesses |

## Goals

- Build confidence in math through guided, step-by-step learning
- Provide instant help/hints so kids don't get stuck or frustrated
- Organize content by category (arithmetic, geometry, fractions & decimals, algebra)
- Scale difficulty by age/grade level


## Non-Goals (v1 / MVP)

- Multiplayer or live tutoring
- Offline mode
- Payments or subscriptions
- Teacher/classroom management (post-MVP)
- Mobile apps (web-first)
- Give parents clear progress tracking
