# Minimum Viable Product — Jamatho

## Target Deadline

January 10, 2027

## MVP Scope

### In Scope

| Feature | Description |
|---------|-------------|
| Kid accounts | Register, login |
| 4 math categories | Arithmetic, Geometry, Fractions & Decimals, Algebra |
| 1 lesson per category (MVP) | Explanation + step-by-step worked example |
| Practice problems | With hints, step-by-step guidance |
| End-of-lesson test | 5–10 questions, score shown at end |
| Progress tracking | Completed lessons, scores, time spent per kid |
| Parent dashboard | View child's progress summary |

### Out of Scope (Post-MVP)

- Additional lessons per category (expand to 3–5 each)
- Badges, streaks, gamification
- Teacher/parent dashboard / classroom management
- Email notifications
- Fractions/decimals advanced topics (beyond MVP basics)
- Mobile apps

## Success Metrics

| Metric | Target |
|--------|--------|
| Lesson completion rate | Kid completes ≥ 1 lesson without dropping off |
| Parent dashboard access | Parent can view child's progress within 2 clicks |
| Critical bugs | < 5 bugs blocking core flow in testing |
| Page load | < 2s on target devices |

## Roadmap Phases

| Phase | Timeline | Focus |
|-------|----------|-------|
| Phase 1 | Now – mid Nov 2026 | MVP core: accounts, categories, lessons, practice, tests, parent dashboard |
| Phase 2 | mid Nov – mid Dec 2026 | Polish, accessibility, bug fixes, more lessons per category |
| Phase 3 | mid Dec – Jan 10, 2027 | Final testing, university submission prep |
