# User Stories — Jamatho

Format: As a [role], I want [goal] so that [benefit].

## Kids

### US-01: Account
**As a kid, I want to sign up and log in** so I can save my progress.

**Acceptance Criteria:**
- Can create account with username and password
- Login persists across browser sessions
- Error message shown for invalid credentials

### US-02: Category Selection
**As a kid, I want to pick a math category** so I can choose what to learn.

**Acceptance Criteria:**
- Category list shows name, short description, and icon
- Categories: Arithmetic, Geometry, Fractions & Decimals, Algebra
- Age-appropriate categories shown based on selected grade

### US-03: Lesson Explanation
**As a kid, I want a step-by-step lesson explanation** so I understand before practicing.

**Acceptance Criteria:**
- Lesson shows text explanation and worked example
- "Next" button advances through steps
- Can go back to previous step

### US-04: Hints
**As a kid, I want hints when I'm stuck** so I don't get frustrated.

**Acceptance Criteria:**
- "Show hint" button reveals step-by-step guidance
- Hint does not reveal the final answer
- Multiple hints available per problem

### US-05: Lesson Test
**As a kid, I want a test after the lesson** so I can check what I learned.

**Acceptance Criteria:**
- 5–10 questions per test
- Score shown at end with pass/fail feedback
- Can retry the test

## Parents

### US-06: Parent Account & Child Linking
**As a parent, I want to create an account and link my child** so I can monitor them.

**Acceptance Criteria:**
- Parent can register and log in
- Parent dashboard lists linked child(ren)

### US-07: Progress Visibility
**As a parent, I want to see my child's completed lessons and scores** so I know where they need help.

**Acceptance Criteria:**
- Dashboard shows category, last score, date completed, time spent
- Visual indicator of strengths and weaknesses
